Data flow: MDL lead check

Each week a Marketing user uploads the RB2B website-visitor export. The app checks every visitor against fixed rules and ranks the ones worth following up. Gemini writes the explanation, but never sees names, emails or LinkedIn URLs and never decides the ranking. Nothing uploaded is saved: the file is held in memory and deleted after 30 minutes without activity. Each user sees only their own results.
Contains personal data No names, emails or LinkedIn URLs Later phase, not in the first release

Access and location

  • About 10 named Marketing users. Google sign-in; no public access.
  • Each user sees only their own chats and workbooks.
  • The app runs as its own service account, allowed only to call Gemini and write logs.
  • Testing runs in a lab project in Iowa (us-central1), with made-up or approved files. Marketing's own projects (test, then production) will run in Montréal (northamerica-northeast1).
  • Changes only through code reviewed by Marketing's platform team.
  • Later, users reach it through the company Gemini Enterprise app.
