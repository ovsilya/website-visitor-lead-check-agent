1 · Components inside the Python process

Component view (C4 level 3). Top: ADK handles the request. Middle: our code, called by ADK through its extension points (plugin, tools). Bottom: everything is held in this process's memory.

2 · What the ADK Runner does for one POST /run

ADK does the orchestration; our code runs only at steps 2 and 5. ADK library · ours our code.
1Load sessionADK
SESSIONS.get_session(app, user, id). The user ID is the email the access check verified.
2Plugin hookours
on_user_message_callback swaps the file for a placeholder. Returning a new Content replaces the message.
3Store messageADK
The cleaned message is appended to the session as an event. The file never reaches the session.
4Call GeminiADK
Builds the request: instruction + history + tool declarations. Gemini replies with a function_call.
5Run the toolours
ADK calls check_leads(tool_context, top_n) and stores the returned dict as a function_response event.
6Call Gemini againADK
With the summary JSON. Gemini writes the 2–4 sentences; no more tool calls, so the loop ends.
7Return eventsADK
All events go back to the page. It draws the card from the function_response and shows Gemini's text.

3 · check_leads, step by step

Two lanes: the tool runs on the event loop (async I/O, ADK calls); the engine runs in a worker thread (CPU-bound pandas), so other requests aren't blocked. One input, two outputs: a summary without names for Gemini, and the full workbook for the user.

4 · The decision for one person (_check_person)

Four independent checks, then one rule. Every threshold, list and weight comes from lead_check/lists/, so Marketing can change them without a code change.
Who
Strong role?titles.role(title): leads or buys AI/data (heads, directors, VPs, CTOs, procurement) or does it hands-on (ML engineers, data scientists, researchers).
✓ LEADS or PRACTITIONER
Which
Tier 1 or 2 account?match_account(website, company) via accounts, account_aliases, company_names. Otherwise a new logo if revenue is above $50M and not Education.
✓ tier is 1 or 2
What
Strong interest?page_kinds(recent_urls): regexes from pages.csv on pages seen in the visit window (14 days to the newest visit in the file).
✓ Contact Us or a solution page
Rule out
Any reason to drop?Own staff · competitor · wrong company match from a personal email · student or job seeker · outside the focus regions (locate(city, state)).
✕ any one rules them out
→
Result
RULED OUTif any rule-out applies
YESelse if Who, Which and What all pass
NOotherwise, with the reasons
Points (rank YESes only, max 10)
Contact Us +3 · service page +2 · leads/buys +2 or practitioner +1 · AI article +1 · 2+ visits +1 · seen in last 7 days +1
Flags: find work email · partner company · region unknown.
ICP label (YES only, icp_label): Physical AI / GenAI data / both / AI Data (general), from AI Data page paths and the title, else the account segment. Never changes the result.

The plugin hooklead_agent/uploads.py
class InMemoryUploadsPlugin(BasePlugin):
    async def on_user_message_callback(self, *, invocation_context, user_message):
        parts = user_message.parts or []
        if all(_plain_text(p) for p in parts):
            return None                       # unchanged
        entry = _UPLOADS.setdefault(invocation_context.session.id, …)
        for p in parts:
            if p.inline_data is None:          # fail closed
                new_parts.append(Part(text=p.text) if _plain_text(p)
                    else Part(text="[Removed: only files uploaded on the page …]"))
                continue
            entry["files"][name] = p.inline_data.data   # bytes stay here
            new_parts.append(Part(text=placeholder(name)))
        return types.Content(role=user_message.role, parts=new_parts)
Returning a Content from this callback replaces the user's message before ADK stores it or sends it to Gemini.

Conventions

  • Rules are pure functions. The engine never touches the network, disk, ADK or Gemini, so it runs the same in tests, the CLI and the app.
  • ADK only at the edges: one plugin, two tools, one App. No custom agent classes.
  • Blocking work off the event loop: asyncio.to_thread for the engine, the workbook and the legacy script.

Where personal data can be

  • _UPLOADS, the engine's DataFrames, the scratch folder and the workbook artifact.
  • Never in session events, the summary dict or anything sent to Gemini, unless SHARE_NAMES_WITH_MODEL=true.
  • Error text can quote rows, so @_safe never forwards it.

Errors

  • LeadCheckError / BaselineError: expected problems (not an RB2B file, no dates). The message goes back as {"status":"error"}.
  • Anything else: @_safe returns a generic message.
  • Gemini explains the error to the user; the instruction tells it what to ask for.
